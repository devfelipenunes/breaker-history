# Bancos de dados exportados

Os quatro arquivos `.txt` contêm snapshots JSON formatados das bases do Notion. Eles preservam os registros e propriedades exportados, junto com a URL da fonte e a data de exportação. Use-os como referência de dados; a documentação editorial legível está em `pages/`.

- [Decisões narrativas do Act I](act-i-story-decisions.txt)
- [Cartões de cena da Season 1](season-01-scene-cards.txt)
- [Catálogo de referências da Season 1](season-01-reference-catalog.txt)
- [Fila de publicações da Season 1](season-01-publication-queue.txt)

O [manifesto](../manifest.json) relaciona cada página ou exportação à origem no Notion. Links externos nos registros permanecem apontando para o Notion quando a página de origem não foi exportada individualmente.
