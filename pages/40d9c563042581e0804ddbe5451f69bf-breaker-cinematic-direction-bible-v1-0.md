NORMA VISUAL OFICIAL — Aplicar a todos os storyboards, prompts de imagem, slides e revisões. A Season 1 é o piloto de validação. A linguagem cinematográfica serve à compreensão, tensão e agência do jogador, não ao espetáculo gratuito.
</callout>

# 1. Princípio diretor

Toda imagem deve responder: (1) o que o jogador precisa perceber? (2) o que deve sentir? (3) o que deve permanecer oculto? (4) por que este plano vem antes do próximo? Se não houver resposta, redesenhar.

# 2. Gramática de planos

| Plano | Função preferencial no Breaker |
| --- | --- |
| EWS / plano geral extremo | Escala do sistema, isolamento, mundo institucional |
| WS / plano geral | Localização e relações espaciais |
| MS / plano médio | Ação, decisão e interação entre personagens |
| MCU / plano médio fechado | Dúvida, negociação, ameaça velada |
| CU / close-up | Reação, descoberta e mudança emocional |
| ECU / detalhe extremo | Evidência, falha, assinatura, pista |
| OTS / sobre o ombro | Confronto e assimetria de informação |
| POV / ponto de vista | Colocar o jogador na posição de quem investiga |
| Insert / plano de inserção | Interface, objeto ou informação indispensável |

Regra: alternar escala com intenção. Não encadear close-ups apenas para parecer intenso.

# 3. Ângulo e poder

- Eye level: observação e neutralidade aparente.
- High angle / plongée: vulnerabilidade, vigilância ou perda de controle, somente quando coerente.
- Low angle / contra-plongée: domínio, ameaça ou autoridade percebida.
- Dutch angle: ruptura de estabilidade; uso raro, reservado a momentos realmente anômalos.
- Overhead: sistemas, padrões e arquitetura de controle.<br />Ângulo não determina emoção sozinho; combinar com contexto, iluminação e composição.

# 4. Composição e mise-en-scène

- Regra dos terços como ponto de partida, não obrigação.
- Simetria para ordem institucional; quebra de simetria para fissuras na ordem.
- Espaço negativo para solidão, vigilância e informação ausente.
- Linhas-guia e profundidade para conduzir atenção à evidência.
- Silhuetas e hierarquia de contraste para leitura rápida em tela pequena.
- Mise-en-scène: cada tela, objeto, figurino, gesto e fonte de luz deve ser consistente com o mundo.
- Priorizar legibilidade de pistas e interfaces sobre efeitos cinematográficos.

# 5. Continuidade e montagem

- Regra dos 180°: preservar lados e direção de olhar entre planos, exceto desorientação deliberada.
- Regra dos 30°: evitar cortes entre enquadramentos quase idênticos que produzam salto involuntário; é heurística, não lei.
- Eyeline match: mostrar o que o personagem observa com orientação inteligível.
- Match on action: manter continuidade de gesto entre slides.
- Shot/reverse shot: usar em confrontos com economia de diálogo.
- Cutaway/insert: revelar evidência ou consequência sem exposição verbal.
- Montagem associativa / efeito Kuleshov: a interpretação de uma imagem depende da imagem anterior e posterior; validar a sequência inteira, não cada slide isoladamente.
- Ritmo: estabelecer → aproximar → revelar → reação → consequência. Variar quando o suspense exigir.
- Quebrar continuidade apenas quando a desorientação for uma decisão narrativa documentada.

# 6. Luz, cor e lentes

- Luz motivada: terminais, janelas, telas e luminárias devem justificar a iluminação principal quando possível.
- Alto contraste para risco e ambiguidade; contraste moderado para investigação e leitura de evidências.
- Cor como continuidade semântica: definir paleta por local, facção e estado dramático; evitar cores aleatórias entre slides.
- Profundidade de campo rasa para isolar detalhe; profunda para cenas de investigação que exijam contexto.
- Lentes equivalentes como linguagem de prompt, não exigência técnica: 24–35 mm para espaço/contexto, 40–50 mm para percepção natural, 70–100 mm para isolamento e compressão. Verificar distorção e consistência visual.
- Não usar anamórfico, bloom, flare ou granulação como padrão automático.

# 7. Regras para narrativa em slides

1. Cada slide deve ter uma unidade dramática: nova informação, nova pergunta, escolha ou consequência.
2. Cada transição precisa justificar mudança de tempo, espaço, atenção ou significado.
3. Evitar diálogo redundante com a imagem; preferir comportamento, objeto e consequência.
4. POV do jogador nos momentos de investigação/decisão; câmera externa quando a história precisa mostrar algo que ele não sabe.
5. A pergunta interativa não deve interromper o clímax nem fingir alterar a história quando não altera; pode testar observação ou interpretação.
6. Informação crítica deve permanecer compreensível sem movimento, áudio ou animação.
7. Manter direção de luz, posição de objetos, roupa, geografia e estado das interfaces entre slides.

# 8. Shot card obrigatório por slide

| Campo | Preenchimento |
| --- | --- |
| ID | S1-Ato-Cena-Slide |
| Objetivo dramático | O que muda neste instante? |
| Informação visível / oculta | O que o jogador sabe e ainda não sabe? |
| Plano / ângulo / POV | Siglas e justificativa |
| Composição / foco | Sujeito principal, hierarquia visual |
| Luz / cor | Fonte motivada e paleta da cena |
| Continuidade | Eixo, olhar, objetos, estado, posição |
| Transição | Corte, correspondência, revelação, pausa |
| Interação | Nenhuma / observação / interpretação / escolha |
| Prompt de imagem | Descrição visual com elementos persistentes |
| QA | Clareza, emoção, coerência, continuidade, acessibilidade |

# 9. Checklist de aprovação

- [ ] O enquadramento tem função narrativa explícita.
- [ ] A informação essencial é legível sem depender de texto longo.
- [ ] A sequência preserva continuidade espacial e temporal.
- [ ] O olhar do jogador é direcionado ao elemento correto.
- [ ] O uso de luz, cor e lente é coerente com a cena.
- [ ] A cena respeita o cânone e o estado dos personagens.
- [ ] A tensão vem da revelação e das consequências, não apenas do filtro visual.
- [ ] A interação, se existir, tem propósito claro.
- [ ] O storyboard foi revisado como sequência completa.
- [ ] Exceções às regras estão justificadas.

# 10. Fluxo obrigatório de produção

Roteiro canônico → intenção dramática → beat visual → shot list → storyboard → checagem de continuidade → geração de imagem → montagem de slides → teste de leitura sem áudio → revisão final. Se a cena falhar no teste, voltar ao storyboard.

# 11. Direção específica da Season 1

A câmera começa predominantemente observacional, clara e espacialmente estável. Conforme o jogador encontra contradições no sistema, aproximar progressivamente a atenção a evidências e reações; reservar rupturas formais para viradas relevantes. Não antecipar segredos com enquadramentos que revelem informações fora do ponto de vista narrativo autorizado. Priorizar progressão de compreensão e tensão em vez de aumentar a complexidade visual em todas as cenas.
